Kargo

Neredeyse hiç kullanıcı arayüzü olmayan, klavye odaklı bir tarayıcı.

Şimdi İndir

Kargo yeni bir tarayıcıdır.

Kargo, internette yaşayan ve fareden nefret eden insanlar için tasarlanmış bir tarayıcıdır. Kargo, sadece birkaç klavye kısayolu kullanılarak kontrol edilebilir. Kargo, bir tarayıcının sadece en kullanışlı özelliklerini içerir; bu sayede internette gezinirken gereksiz özellikler sizi rahatsız edemez. Kargo'yu geliştirdim çünkü tercih ettiğim tarayıcıların (Chrome ve Firefox) sahip olduğu çoğu özelliği kullanmıyordum.

Kargo; Javascript, HTML ve CSS kullanarak modern, platformlar arası masaüstü uygulamaları geliştirmeye yarayan bir teknoloji olan Electron kullanılarak inşa edilmiştir. Kaynak koduna Github üzerinden ulaşılabilir.

Özellikler

  • Chrome: Kargo, gücünü Chromium'dan alan Electron'un webview etiketlerini kullanır.
  • Sekmeler: Diğer tüm tarayıcılar gibi Kargo da sekmeleri destekler, ancak bunları sizden gizler.
  • Popup'lar sekme olur: target="_blank" ile açılan bağlantılar ve window.open çağrıları yeni pencere yerine Kargo sekmesinde açılır. OAuth gibi gerçek pencere gerektiren akışlar güvenli bir pencerede çalışmaya devam eder.
  • Kargo'ya özel sağ tık menüsü: Kes, kopyala, yapıştır ve tümünü seç işlemleri sade bir menüde toplanır.
  • Özelleştirilebilir kısayollar: Ayarlar sayfasından her kısayolu kendi alışkanlığına göre değiştirebilirsin.
  • Geliştirici Araçları: Kargo, Chrome'un geliştirici araçlarını tam olarak destekler.
  • PDF ve tam ekran: PDF dosyaları tarayıcı içinde açılır, HTML5 tam ekranı desteklenir.
  • Platformlar arası: Kargo tüm platformlarda iyi görünür, Windows'taki başlık çubuğu bile şık durur.
  • Basit: Kargo sadece çoğu insanın ihtiyaç duyduğu özelliklere sahiptir.
  • Çok şirin: 🚂🚋🚋 Kargo (web'i evinize taşır)

Klavye Kısayolları

Bu tablo varsayılan kısayolları gösterir. Kargo'yu ilk kez başlattığında veya ayarları sıfırladığında bu kombinasyonlar geçerli olur.

Sekmeler

Ctrl + T Yeni sekme aç
Ctrl + X Mevcut sekmeyi kapat
Ctrl + Shift + T Sekme çubuğunu göster/gizle
Ctrl + Shift + ← Önceki sekme
Ctrl + Shift + → Sonraki sekme
Ctrl + 1 … 9 İlgili sekmeye geç

Gezinme

Ctrl + ← Geri git
Ctrl + → İleri git
Ctrl + Shift + H Ana sayfaya git
Ctrl + Shift + S Ayarlar sayfasını aç
Ctrl + Shift + A Hakkında sayfasını aç

Tarayıcı

Ctrl + R / F5 Sayfayı yenile
Ctrl + K Arama alanına odaklan
Ctrl + = Yakınlaştır
Ctrl + - Uzaklaştır
Ctrl + 0 Yakınlaştırmayı sıfırla

Pencere

Ctrl + M Pencereyi küçült
Ctrl + Shift + M Pencereyi büyüt
Ctrl + Q Uygulamayı kapat

Kısayolları Ayarlar → Kısayollar bölümünden değiştirebilirsin: bir kısayola tıklayıp yeni tuş kombinasyonuna bas. Esc kaydı iptal eder, ↺ tek kısayolu, Varsayılanlara dön ise tümünü sıfırlar. Aynı kombinasyonu iki kısayola vermeye çalışırsan eski sahibi boşa alınır.
